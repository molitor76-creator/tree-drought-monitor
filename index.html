How to read the graph: Each point represents the model's estimated soil-water storage on that date, in millimetres (mm). One millimetre is equivalent to one litre of water per square metre. The point colour shows the modelled drought severity. Hover over a point to see its exact storage, severity and consecutive stress days.

Watering targets: Each dashed line represents the model's target storage for that location. The watering recommendation is the difference between the current estimated storage and this target, expressed in litres per square metre.

Important: These are model estimates, not direct soil-moisture measurements. The model assumes all rainfall enters the reservoir and uses reference evapotranspiration as a proxy for water loss. The soil capacities and the 60% target are provisional assumptions.
